# 🎯 Tasker

Automated Task Management System built with Node.js and TypeScript.

## 🛠 Tech Stack
- **Language**: TypeScript
- **Runtime**: Node.js
- **Protocol**: GPDC + Mind-Vault Sprint Workflow

## 📁 Structure
- `src/` - Source code
- `docs/` - Project documentation and Sprint artifacts
- `rules/` - Behavioral guardrails (Mind-Vault)
