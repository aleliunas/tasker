# GPDC & Sprint Workflow

Always follow the GPDC (Goal, Plan, Do, Check) cycle for every task.
Use the mind-vault Sprint Workflow:
1. /idea - Capture feature or bug.
2. /plan - Architect the solution.
3. /work - Execute the plan.
4. /wrap - Cleanup and document.
5. /compound - Promote learnings.

Rules:
- Never start work without a confirmed Plan.
- Always use surgical edits.
- Tag assumptions with [PRIELAIDA].
